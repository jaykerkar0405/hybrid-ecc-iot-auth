# Security policy

This is a research and teaching artifact, not a production security product. It is
not hardened against side channels, and its keystore is demo-grade.

If you find a flaw in the protocol implementation or tooling, please report it
privately through GitHub's "Report a vulnerability" (Security tab) instead of
opening a public issue. Protocol-level weaknesses of the source paper that we
already document (for example, no forward secrecy) are described in
`research/paper_audit/FINDINGS.md`.
